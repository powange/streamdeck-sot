Obtenir une clé OpenXBL
  1. Va sur https://xbl.io et connecte-toi avec ton compte Microsoft / Xbox.
  2. Dans le tableau de bord, crée une clé API (« API Keys ») et colle-la ci-dessus.

OpenXBL est un service tiers. L'offre gratuite est limitée (~150 requêtes / heure), les données sont donc mises en cache 10 minutes.
